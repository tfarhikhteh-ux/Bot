# سامانه جامع مدیریت هوشمند مدرسه — کاملاً داخل پیام‌رسان بله (`School Bot`)

نسخه: **2.0.0** | پلتفرم هدف: **Windows 10/11، Windows Server و Linux** | نسخه پایتون: **Python 3.11 / 3.12**

---

## ۱. معرفی پروژه
**School Bot** یک سامانه یکپارچه، امن و ماژولار برای مدیریت کامل امور آموزشی، انضباطی، تقویمی، کارنامه آنلاین و گروه‌های کلاسی مدرسه **منحصراً در داخل پیام‌رسان بله (`balethon`)** با پایگاه داده تراکنشی **SQLite** است. هیچ پنل وب یا سرویس خارج از بله وجود ندارد و **تمامی امکانات مدیریتی، آموزشی، خروجی‌ها و فایل‌های پشتیبان مستقیماً داخل بله** انجام و تحویل داده می‌شوند.

---

## ۲. ویژگی‌های کلیدی (تماماً داخل بله)
- **ثبت‌نام مرحله‌به‌مرحله هوشمند** متناسب با نقش و ارسال خودکار درخواست‌ها **صرفاً به گروه مدیریتی مدرسه در بله** همراه با دکمه‌های تأیید/رد شیشه‌ای.
- **کنترل دسترسی سخت‌گیرانه (RBAC)** در هر دو لایه Handler و Service برای ۷ نقش سازمانی (`ADMIN`, `SCHOOL_MANAGER`, `DEPUTY`, `TEACHER`, `ASSOCIATION_MEMBER`, `PARENT`, `STUDENT`).
- **برنامه هفتگی پیشرفته با پشتیبانی کامل از «هفته اول»، «هفته دوم» و دروس مشترک هر دو هفته**، تشخیص خودکار تداخل برنامه دبیران و کلاس‌ها، دستور متنی سریع `/برنامه_ویرایش` و ارسال مستقیم خروجی تصویری (`PNG`)، چاپی (`PDF`) و اکسل (`XLSX`) در چت بله.
- **سامانه حضور و غیاب زنگ‌به‌زنگ** با ۶ وضعیت استاندارد، جلوگیری از ثبت تکراری، اصلاح وضعیت با ثبت الزامی علت، مسدودسازی ثبت عادی در روزهای تعطیل رسمی، ثبت موارد انضباطی و اطلاع‌رسانی خودکار به والدین در بله.
- **کارنامه آنلاین ۲۴ ساعته کاملاً داخل بله**: نمایش آنی و زنده کارنامه متنی، تفکیک شفاف نمره مستمر و پایانی، محاسبه دقیق معدل وزنی از ۲۰، دکمه **«🔄 بروزرسانی لحظه‌ای کارنامه»** و ارسال مستقیم فایل **PDF** و **اکسل راست‌به‌چپ (`XLSX`)** در چت بله.
- **موتور یکپارچه دستورات دو روشه برای تمام کارکنان (ریپلای در گروه یا فوروارد پیام فرد به شخصی ربات + دکمه‌های سریع نقش)**: هر یک از کارکنان (**ادمین، مدیر، ناظم، معلم و انجمن**) می‌تواند یا در گروه روی پیام فرد ریپلای کند و دستور بدهد، یا پیام فرد را به شخصی (پی‌وی) ربات فوروارد کند و دستور را تایپ کند یا از دکمه‌های شیشه‌ای مخصوص نقش خود استفاده نماید (حضور/غیاب سریع، ثبت مورد انضباطی/تشویقی، مشاهده وضعیت و کارنامه، فعال/غیرفعال‌سازی و تغییر نقش — دقیقاً در سقف مجوز همان نقش).
- **ثبت آنی «مثبت درسی» (+۱) و «منفی درسی» (-۱) منحصراً مخصوص معلمِ درس**: فقط و فقط معلمِ درس (`TEACHER`) مجاز به ثبت مثبت و منفی درسی (به هر دو روش ریپلای در گروه یا فوروارد به پی‌وی ربات) است و امتیاز **صرفاً روی نمره مستمر (و هرگز روی نمره پایانی)** اعمال می‌گردد.
- **مدیریت کامل قفل گیف، رسانه، لینک، فوروارد و چت گروه منطبق با API رسمی بازوی بله**: پشتیبانی از دستورات `قفل گیف`، `قفل باز گیف` (و `باز گیف`)، `قفل رسانه` / `باز رسانه`، `قفل استیکر`، `قفل عکس`، `قفل فیلم`، `قفل ویس`، `قفل صوت`، `قفل فایل`، `قفل لینک`، `قفل فوروارد`، `قفل گروه`، `پنل قفل` و `اتصال کلاس <نام کلاس>` (ادمین، مدیر، ناظم و انجمن در همه گروه‌ها و **معلم فقط در گروه کلاس خودش**).
- **پشتیبان‌گیری آنلاین SQLite و ارسال مستقیم فایل بکاپ در چت بله** با بررسی `SHA-256` و `PRAGMA integrity_check`، نگهداری چرخشی و بازیابی امن با تأیید دو مرحله‌ای در بله.

## ۳. معماری پروژه
```text
school_bot/
├── main.py                  # نقطه ورود ربات بله (bot / migrate / backup / restore)
├── config.py                # بارگذاری و اعتبارسنجی سخت‌گیرانه تنظیمات محیطی (.env)
├── requirements.txt         # وابستگی‌های خالص ربات بله و گزارش‌سازها (بدون هیچ وابستگی وب)
├── .env.example             # الگوی تنظیمات محیطی
├── database/
│   ├── schema.sql           # تعریف جداول رابطه‌ای، کلیدهای خارجی و ایندکس‌ها
│   ├── db.py                # مدیریت اتصال Thread-Safe، حالت WAL و تراکنش‌های اتمیک
│   ├── migrations.py        # سیستم نسخه‌بندی و ارتقای خودکار ساختار دیتابیس
│   └── repositories/        # ۱۲ مخزن داده تفکیک‌شده برای موجودیت‌های سامانه
├── services/                # منطق کسب‌وکار، RBAC، صف پیام، قفل گروه‌ها، گزارش و پشتیبان‌گیری
├── handlers/                # ۱۶ ماژول هندلر پیام‌ها، دستورها، دکمه‌ها و فرم‌های چندمرحله‌ای بله
├── keyboards/               # کیبوردهای متنی و شیشه‌ای اختصاصی هر نقش در بله
├── utils/                   # تقویم شمسی، اعتبارسنجی، رندر خروجی‌ها، اتصال مقاوم بله و لاگ امن
├── tests/                   # مجموعه تست‌های خودکار واحد و یکپارچه (pytest)
├── backups/                 # محل نگهداری نسخه‌های پشتیبان دیتابیس
└── logs/                    # محل نگهداری فایل‌های لاگ چرخشی سامانه
```

## ۴. نصب و راه‌اندازی سریع
۱. ساخت و فعال‌سازی محیط مجازی پایتون (Python 3.11 یا 3.12):
```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```
۲. ساخت فایل `.env` از روی نمونه و وارد کردن `BALE_BOT_TOKEN`، `PRIMARY_ADMIN_ID` و `MANAGEMENT_GROUP_ID`:
```powershell
Copy-Item .env.example .env
notepad .env
```
۳. آماده‌سازی پایگاه داده و اجرای مستقیم ربات بله:
```powershell
python main.py migrate
python main.py
```

## ۵. راهنمای دستورها در بله
با ارسال `/دستورها` (یا `/help`) در ربات بله، فهرست کامل دستورهای مجاز متناسب با نقش شما نمایش داده می‌شود:
- `/start`: ورود به سامانه و نمایش منوی اختصاصی نقش در بله
- `/دستورها` (یا `/help`): نمایش راهنمای دستورهای مجاز نقش کاربر
- `/لغو` (یا `/منو` یا `/cancel`): لغو فرم جاری و بازگشت به منوی اصلی
- `/مدیریت`: پنل مدیریت کل و مدیریت مدرسه در بله (`ADMIN` و `SCHOOL_MANAGER`)
- `/برنامه`: مشاهده برنامه هفتگی کلاس یا برنامه تدریس شخصی دبیر + دریافت PNG / PDF / اکسل در بله
- `/برنامه_ویرایش کلاس | روز | زنگ | هفته | درس`: ویرایش سریع خانه برنامه هفتگی
- `/حضور`: ثبت و مشاهده حضور و غیاب زنگ‌به‌زنگ در بله
- `/کارنامه`: مشاهده کارنامه آنلاین ۲۴ ساعته در چت بله + بروزرسانی لحظه‌ای + دریافت PDF و اکسل (`XLSX`)
- `/تقویم`: مشاهده تقویم آموزشی و تعطیلات پیش رو
- `/پشتیبان`: تهیه، دریافت مستقیم فایل `.db` در چت بله و بازیابی امن دیتابیس (انحصاری `ADMIN`)
- `قفل گیف` / `قفل باز گیف` / `قفل رسانه` / `پنل قفل` / `اتصال کلاس <نام کلاس>`: مدیریت کامل قفل‌های گروه بله
